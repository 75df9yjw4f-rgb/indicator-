# CVD Divergence Scalper [1m] — BTCUSDT

Чистый **`indicator()`** на Pine Script v6 (не strategy, без Strategy Tester, без SL/TP
и статистики). Файл: **`CVD_Divergence_Scalper.pine`** — вставить в Pine Editor →
`Add to chart`.

Скрипт открывается **нижней панелью** с CVD-свечами; EMA, линии дивергенции по цене,
сигналы и линия виртуальной позиции выводятся на **основной график** через
`force_overlay = true`.

```
PRICE CLOSE STRUCTURE
        ↓
CVD CLOSE STRUCTURE
        ↓
поиск расхождения среди последних N pivot'ов
        ↓
максимум 2 дивергенции на графике
        ↓
ожидание EMA (15 баров)
        ↓
EMA сигнал → LONG / SHORT
        ↓
виртуальная позиция
```

## Архитектура

1. **CVD** считается ровно как в `Cumulative Delta Volume` (CDV) LonesomeTheBlue: объём
   каждой свечи графика делится на покупки/продажи по форме самой свечи (верхняя тень,
   нижняя тень, тело) и накапливается через `ta.cum()`. Никаких младших таймфреймов,
   никакой реконструкции, никаких собственных формул.
2. **CVD-свеча** — оригинальная: `o = cvd[1]`, `h = max(cvd, cvd[1])`,
   `l = min(cvd, cvd[1])`, `c = cvd`. Heikin Ashi — отдельная настройка (только вид).
3. **Структура читается только по закрытиям**: пивоты цены по `close`, пивоты CVD по
   сырому накопленному дельта-значению (CVD close). Тени, HA-значения и внутрисвечные
   экстремумы в сравнении не участвуют вообще.
4. **Пивоты** — `ta.pivothigh` / `ta.pivotlow` с раздельными Left/Right для цены и CVD
   (по умолчанию 2/2). Пивот существует только после закрытия `Right` баров → repaint
   структуры невозможен.
5. Подтверждённые пивоты лежат в четырёх маленьких кольцевых буферах: максимумы цены,
   минимумы цены, максимумы CVD, минимумы CVD.
6. **Сопоставление**: каждому ценовому пивоту ищется ближайший подтверждённый пивот CVD
   **того же типа** в пределах `Pivot Matching Window` (5 баров). High только с High,
   Low только с Low.
7. Если пивот CVD подтверждается **позже** ценового — ценовой остаётся без пары и
   получает её именно на том баре, когда CVD-пивот подтвердился. Раньше — никогда.
8. **Поиск дивергенции**: от нового пивота скрипт идёт назад по последним
   `Historical Pivots To Scan` (20) пивотам того же типа и берёт первое найденное
   структурное расхождение. Это не сравнение «только с предыдущим».
9. **4 типа**: 1 = HH/LH, 2 = LL/HL, 3 = HL/LL, 4 = LH/HH. Каждый включается отдельно.
10. **Рисование**: толстая линия между двумя закрытиями цены на основном графике +
    толстая линия между двумя закрытиями CVD на панели CVD + компактная метка типа.
11. **Максимум 2 дивергенции на экране** (`Max Visible Divergences`, потолок 2). При
    появлении новой самая старая отрисовка удаляется.
12. **История для сигналов хранится отдельно** — два номера бара (последняя bullish- и
    последняя bearish-дивергенция), поэтому удаление отрисовки не теряет информацию.
13. Дивергенция только **взводит** систему. Событие входа — одно пересечение **одной**
    EMA в пределах `Max Bars After Divergence` (15 баров).
14. **Signal Mode**: `After Candle Close` (по умолчанию, не перерисовывается) или
    `Immediately On Cross` (см. ограничение ниже). **Direction Filter**: `Strict`
    (HH/LH и LH/HH → только SHORT, LL/HL и HL/LL → только LONG) или `Any`.
15. **Виртуальная позиция** FLAT / LONG / SHORT: встречный сигнал всегда рисуется, но
    вторую позицию не открывает.

## Честное ограничение

Pine не видит внутрисвечное движение на исторических барах, поэтому «настоящее»
intrabar-пересечение для истории восстановить нельзя. Режим `Immediately On Cross`
поэтому **на всей истории работает идентично** `After Candle Close` и отличается только
на **живом баре**, где метка может появиться и снова исчезнуть до закрытия свечи. Ничего
не имитируется. Для non-repainting сигналов оставляйте режим по умолчанию.

## Настройки

| Группа | Параметры |
|---|---|
| **CVD** | Use Heikin Ashi CVD candles, Show CVD candles (ON), Show CVD line (OFF), цвета свечей и линии |
| **Structure** | Price Pivot Left/Right (2/2), CVD Pivot Left/Right (2/2), Show price pivots, Show CVD pivots |
| **Divergence** | Historical Pivots To Scan (20), Pivot Matching Window (5), Type 1–4 ON/OFF, Max Visible Divergences (2), линии на price/CVD, Divergence Line Width (3), цвета bullish/bearish |
| **EMA** | Show EMA, EMA Length (20), цвет, толщина |
| **Signals** | Max Bars After Divergence (15), Signal Mode, Divergence Direction Filter, Show Signals, размер сигнала, «встречный сигнал закрывает позицию» |
| **Visuals** | Show Entry, Show Position, цвет и толщина линии входа |

Два момента, которые стоит знать:

* **Heikin Ashi по умолчанию выключен.** Структура всегда считается по сырому CVD close,
  а HA-свечи рисуют другие значения — при HA = ON линии дивергенции по CVD перестанут
  ложиться точно на тела свечей. Включайте, если важнее сглаженный вид.
* **«Встречный сигнал закрывает виртуальную позицию» по умолчанию включено.** В ТЗ
  описаны только переходы FLAT → LONG и FLAT → SHORT, без выхода, иначе состояние
  залипло бы навсегда после первого сигнала. Встречный сигнал переводит позицию в FLAT
  и **не** открывает противоположную. Выключите, если нужно иное поведение.

## Проверка перед публикацией

Проведены статические проверки: баланс скобок, отступы продолжений строк, отсутствие
локальных объявлений функций, отсутствие присваиваний необъявленным переменным,
использование функций после их объявления, полное отсутствие `request.*`, `security`,
`lookahead` и `strategy.*`, пивоты только по `close`/`cvd`, ровно одна `ta.ema`,
жёсткий потолок в 2 видимые дивергенции.
