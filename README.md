# CVD Divergence + EMA Signals — BTCUSDT 1m

Обычный **`indicator()`** на Pine Script v6. Не strategy, без Strategy Tester, SL/TP,
ATR/RSI/MACD, дополнительных EMA, фильтров и таблиц.

Файл: **`CVD_Divergence_Scalper.pine`** → Pine Editor → `Add to chart`.
Скрипт открывается нижней панелью с CVD-свечами; EMA, линия дивергенции по цене,
сигналы и виртуальная позиция выводятся на основной график (`force_overlay = true`).

```
PRICE CLOSE → структурные High/Low → 4 ближайших предыдущих High и Low
        ↓
сравнение структуры Price Close и CVD Close
        ↓
дивергенция (макс. 2 видимые)
        ↓
ожидание EMA (15 свечей)
        ↓
EMA cross → LONG / SHORT
```

## Архитектура

1. **CVD** — формула CDV LonesomeTheBlue без изменений: объём свечи делится на
   покупки/продажи по её форме (тени + тело) и накапливается. Никаких младших ТФ,
   никакого `request.security_lower_tf()`, никакой своей реконструкции.
2. **CVD рисуется свечами**: `o = cvd[1]`, `h = max(cvd, cvd[1])`, `l = min(cvd, cvd[1])`,
   `c = cvd`. Heikin Ashi — только визуальная настройка, на расчёт не влияет.
3. **Дивергенция считается только по закрытиям**: Price Close ↔ CVD Close. Тени цены,
   CVD High/Low и HA-значения в сравнении не участвуют.
4. Структурные свинги находятся через `ta.pivothigh`/`ta.pivotlow` по `close`.
   **Left/Right только НАХОДЯТ свинг и гарантируют его подтверждение** (нужно закрытие
   `Right` баров) — это не параметр поиска дивергенции.
5. **Параметр поиска — `Pivots To Compare = 4`**: новый High сравнивается с 4 ближайшими
   предыдущими High (H-1, H-2, H-3, H-4), новый Low — с 4 ближайшими предыдущими Low.
   Более старые pivot'ы не рассматриваются вообще.
6. High сравнивается только с High, Low только с Low.
7. Каждому ценовому pivot ищется пара — ближайший **подтверждённый** CVD pivot того же
   типа в пределах `Pivot Matching Window` (5 баров). Нет пары — нет дивергенции.
8. Если CVD pivot подтверждается **позже** ценового, пара закрывается именно на том
   позднем баре. Задним числом ничего не создаётся.
9. **Порядок сравнения — от ближайшего**: H-1, затем H-2, H-3, H-4. Первое найденное
   расхождение выигрывает, поиск останавливается: один новый pivot рисует максимум одну
   дивергенцию.
10. **4 типа**: 1 = HH/LH, 2 = LL/HL, 3 = HL/LL, 4 = LH/HH, каждый включается отдельно.
11. Отрисовка: толстая линия Close→Close на цене + толстая линия CVD Close→CVD Close на
    панели CVD + маленькая метка типа. Тени не соединяются никогда.
12. **Максимум 2 видимые дивергенции**; самая старая отрисовка удаляется. Номера баров
    для логики сигналов хранятся отдельно, поэтому удаление линии ничего не ломает.
13. Дивергенция **не вход**, она создаёт **одно ожидание сигнала**. Его закрывает
    **первое подходящее** пересечение **одной** EMA в пределах `Max Bars After
    Divergence` (15 свечей): выдаётся один сигнал, ожидание гасится, и следующие
    пересечения молчат до **новой** дивергенции. Не дождались — ожидание истекает
    без сигнала.
14. **Direction Filter**: `Strict` (HH/LH и LH/HH → только SHORT, LL/HL и HL/LL → только
    LONG) или `Any` (направление задаёт EMA: вверх → LONG, вниз → SHORT).
15. **Виртуальная позиция** FLAT / LONG / SHORT. Встречный сигнал всегда рисуется;
    что он делает с состоянием, решает `Opposite Signal Behavior` (по умолчанию `Ignore`).

## Честное ограничение

У Pine нет внутрисвечных данных по историческим барам, поэтому intrabar-пересечение для
истории восстановить невозможно. Режим `Immediately On Cross` на всей истории работает
идентично `After Candle Close` и отличается только на **живом баре**, где метка может
появиться и исчезнуть до закрытия свечи. Ничего не имитируется; исторические сигналы не
перерисовываются ни в одном из режимов.

## Настройки

| Группа | Параметры |
|---|---|
| **CVD** | Heikin Ashi CVD candles (display only), цвета свечей |
| **Structure** | **Pivots To Compare = 4**, Price swing Left/Right (2/2), CVD swing Left/Right (2/2) |
| **Divergence** | Pivot Matching Window (5), Type 1–4 ON/OFF, Max Visible Divergences (2), Divergence Line Width (3), цвета bullish/bearish |
| **EMA** | EMA Length (20), цвет, толщина |
| **Signals** | Max Bars After Divergence (15), Signal Mode, Divergence Direction Filter, Opposite Signal Behavior (Ignore) |
| **Visuals** | Show Signals, размер сигнала, Show Historical Entries, цвет/толщина линии входа, Show pivot dots |

Про `Opposite Signal Behavior = Ignore` (значение по умолчанию из ТЗ): встречный сигнал
рисуется, но состояние не меняется — то есть после первого сигнала виртуальная позиция
остаётся открытой, и линия входа тянется дальше. Вариант `Close Virtual Position`
переводит состояние в FLAT (противоположную позицию не открывает), после чего следующий
сигнал снова может открыть виртуальную позицию.

## Проверки

Баланс скобок, отступы продолжений строк, все 11 функций объявлены на глобальном уровне
и до первого использования, присваиваний необъявленным переменным нет, `request.*` /
`security` / `lookahead` / `strategy` в коде отсутствуют (только в комментарии),
пивоты только по `close` и `cvd`, ровно одна `ta.ema`, сравнение ровно с `pivCmp`
ближайшими предыдущими pivot'ами, жёсткий потолок 2 видимых дивергенций.
